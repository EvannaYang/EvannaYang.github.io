# CodeM 数据报表 Demo

依据 Figma 草稿实现的独立交互演示。打开本目录的 `index.html` 即可使用；如需本地 HTTP 预览，在项目根目录运行：

```bash
python3 -m http.server 8767
```

然后访问 `http://localhost:8767/analytics-demo/`。

侧边栏可切换企业数据报表、研发效能和 AI 应用平台。其他菜单仅提供 hover 状态。研发效能先显示 1 秒加载态，AI 应用平台显示无权限状态。

图表使用本地生成的模拟数据。触控板可横向滚动图表；在图表上按住 Shift、Ctrl 或 Command 并滚动可缩放，触控板捏合也可缩放。日期可选区间或快捷范围。空间报表的三种任务视图共用布局；项目空间条形图可独立纵向滚动并切换排序。

素材位于 `assets/`，使用 Figma 设计文件导出的图标与头像。该目录是作品集项目之外的独立演示页面，未纳入现有 `dist/` 或 `release/` 发布流程。
